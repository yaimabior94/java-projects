```

├── Login (Public Route)
└── AppLayout (Protected)
    ├── Sidebar (Navigation)
    ├── Navbar (User Menu)
    └── Routes
        ├── Dashboard (KPIs + Charts)
        ├── Products (Table + CRUD Modal)
        ├── Categories (Table + CRUD Modal)

        ├── Inventory (Table + Update Modal)
        ├── Sales (Table + Create Modal)
        ├── Purchases (Table + Create Modal)
        └── Reports (Table + Filters)

Shared Services
├── API Service (Axios)

└── Custom Hooks (Form, Async, Storage)
```
